# 远端播放

本术语表描述人对远端音乐播放的意图、执行和控制关系。它只定义本次规划的领域语言，不记录技术实现或选型结论。

## 播放与控制

**播放权威**：唯一决定某次远端播放的队列、当前位置和曲目推进的主体。多个控制端可以观察或请求改变它，但不能各自推进同一播放。
_Avoid_: 两端同步播放器、浏览器跟随播放。

**播放会话**：一次具有连续播放意图、目标输出和恢复位置的音乐使用过程。它不是某个网页的生存期，也不是单首曲目。
_Avoid_: 浏览器会话、单曲进程。

**控制端会话**：人发送播放请求和观察状态的交互关系。它与播放会话相关，但不等于音频正在执行的过程。
_Avoid_: 播放会话、音频会话。

**播放意图**：人对播放、暂停或停止的当前要求。它不同于观察到的连接和声音状态。
_Avoid_: 音频事件、连接状态。

**暂停**：暂不推进音频、仍保留可恢复播放关系的状态。
_Avoid_: 停止、释放音箱。

**停止**：撤销继续播放的意图，包括尚未完成的开始或恢复请求。它不代表音箱关机；是否保留队列由播放政策决定。
_Avoid_: 暂停、删除队列、关闭网页。

**曲目结束**：音乐内容本身自然播放到终点。输出失联或准备失败不是曲目结束。
_Avoid_: 连接关闭、输出断开。

## 播放端与输出

**逻辑播放器**：具有稳定身份、可接收控制请求的播放目标。它的存在不要求物理音箱持续连接。
_Avoid_: 当前音频输出、当前蓝牙连接。

**物理输出**：实际产生声音的音箱及其可用音频通路。它可以暂时不存在，而逻辑播放器仍可被发现和控制。
_Avoid_: 逻辑播放器、已配对设备。

**输出就绪**：目标输出已能够接受并正确执行本次播放的状态。已配对或控制端在线本身不证明输出就绪。
_Avoid_: 连接成功、播放器在线。

**输出使用权**：某次播放会话占用物理输出的授权关系。切歌本身不意味着重新占用音箱。
_Avoid_: 永久在线、永久连接。

**待机**：逻辑播放器仍可控制、物理输出已释放或不再保持使用的状态。
_Avoid_: 播放器离线、手动移除设备。

**唤醒**：为新的或恢复的播放意图重新获得输出使用权并准备可听播放的过程。它不承诺为已彻底关机的音箱供电。
_Avoid_: 自动开机、无条件重连。
